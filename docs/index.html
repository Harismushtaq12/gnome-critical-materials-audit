Rare-earth and platinum-group metals are over-represented in AI-predicted crystals

Google DeepMind's GNoME project predicted 554,054 stable inorganic crystals. This audit asks which elements those crystals need. Compared fairly with known materials, they contain rare-earth and platinum-group metals far more often, and these are elements whose supply depends on very few countries.

Much of the gap comes from the elements chosen, not only the kind of compound

The gap can arise in two ways: GNoME may have more of the compound types that often contain these elements (type mix), or it may choose these elements more often inside the same type (within type). The split depends on whose type weights are used.

Compared with random element choice

1.0 means a group uses the family as often as a random choice of elements would. Known materials sit well below 1, GNoME above it.

The gap has two sides. Known materials reflect what chemists have chosen to make, which may be shaped by cost and availability. GNoME also lies above the random baseline and above other computed databases for rare earths, so the dataset itself adds to the gap.

Rare-earth materials lie closer to the stability limit

A material is near-hull when its predicted energy is less than 25 meV/atom below the convex hull of competing phases. Materials with lanthanides whose 4f electrons are frozen in the calculation are near-hull more often.

These checks were added after an internal review. Each one changes one choice in the analysis and asks whether the rare-earth gap survives.

Full tables are in the electronic supplementary information of the paper and in the files R1 to R8 of the results folder.

What this study cannot show

  • It looks at the elements materials contain. It does not show whether any material can be made.
  • Known materials reflect the choices of experimental chemists, so the gap is measured against experimental practice, which has its own preferences.
  • Many GNoME entries may be ordered versions of disordered phases. The study does not correct for this.
  • It does not test the frozen-4f approximation. That needs calculations with explicit 4f electrons.
  • Five-element metal-only compounds can only be compared with other computed databases, and the four-element metal-only type rests on 276 known compounds (the result holds without it).
  • Application performance values are machine-learning predictions.
  • Country data come from mine production and group some elements together.
  • All results refer to the August 2024 release of the GNoME data, and the audit has so far been applied to this one dataset.

Reproduce the results

  1. Open critical_element_audit.ipynb from this repository in Google Colab.
  2. For a quick test, set DEMO_MODE = True and run all cells. It uses fake data and checks that the code works.
  3. For the real run, add a free Materials Project API key as the Colab secret MP_API_KEY, set DEMO_MODE = False and run all cells. The first run downloads about 2 GB; later runs reuse the saved table on Google Drive.
  4. The checks added in revision are in Level 5 of the notebook (R1 to R8). To run only those, keep USE_CHECKPOINT = True, run sections 1 to 5, then the Level 5 cells. They write the R files in results/.
